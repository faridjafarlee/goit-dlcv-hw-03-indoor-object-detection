# ДЗ 3 (тема 8): детекція об'єктів у приміщенні, YOLOv9s

Здавати: `dz_topic_8_Джафарлі_Фарід.ipynb`. Оцінювання: залік або незалік.

Результат на валідації: mAP50 0.507, mAP50-95 0.331, precision 0.546, recall 0.447 (орієнтир з умови: mAP50 від 40 до 60%, mAP50-95 від 25 до 40%). Надійно розпізнаються 4 класи з 10: cabinetDoor, refrigeratorDoor, chair, door. Мету (хоча б 3 класи) досягнуто.

Навчання йшло на GPU Apple M2 Max (mps), 40 епох, близько 50 хвилин. Умова згадує Kaggle або Colab з GPU: ноутбук без змін працює і там (сам знайде дані в /kaggle/input і встановить ultralytics).

Інші файли:
- `build_notebook.py` збирає ноутбук;
- `run_notebook.py` виконує ноутбук і зберігає лише кінцевий стан прогрес-барів, щоб файл не роздувався;
- `data.yaml` конфігурація YOLO (її створює ноутбук);
- `runs/train/` результати навчання, ваги `runs/train/weights/best.pt`; `runs/val/` оцінка на валідації;
- `yolov9s.pt` попередньо навчені ваги;
- `data` посилання на набір даних у кеші kagglehub;
- `dump_outputs.py` перевіряє, що в ноутбуці немає помилок;
- `old_v1/` попередня, розширена версія.

Перезапуск (папку `runs` перед цим видалити):

```bash
../.venv/bin/python build_notebook.py
../.venv/bin/python run_notebook.py dz_topic_8_Джафарлі_Фарід.ipynb
```
